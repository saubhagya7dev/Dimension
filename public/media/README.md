# FPV film

Put your final web-ready MP4 in this folder, for example `fpv-showreel.mp4`.

Then set `fpvVideo: '/media/fpv-showreel.mp4'` in `src/data/site.ts`.
Use an H.264 MP4 with web playback support and keep its transfer size reasonable for mobile connections. The hero is muted; the dedicated film viewer includes playback controls and audio.
